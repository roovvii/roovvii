## Selected work

Most of my banking and insurance code is private under client contracts, so I rebuilt the core of each system as interactive case studies on my portfolio. Every demo linked below is a full slice I built end to end: the backend logic and the React and TypeScript interface that makes it explorable.

- **[Policy Servicing Microservices](https://ravipalavai.vercel.app/projects/policy-servicing-microservices)** — OAuth2/JWT role-based authorization across the full insurance policy lifecycle on Kafka, paired with a React simulator that walks a policy through each stage. 100K+ daily transactions, 30% drop in auth incidents.
- **[Real-Time Fraud Detection Pipeline](https://ravipalavai.vercel.app/projects/real-time-fraud-detection-pipeline)** — Kafka and Spark streaming that scores transactions in under 10 seconds, with a live React dashboard visualizing the decision flow.
- **[Access Control Auditor for Microservices](https://ravipalavai.vercel.app/projects/access-control-auditor-for-microservices)** — a Spring Boot tool that audits service routes for auth and RBAC misconfigurations before release, with a React front end for running audits and reading findings.
- **[Investment Risk Analytics Platform](https://ravipalavai.vercel.app/projects/investment-risk-analytics-platform)** — moved market-risk reporting from overnight batch to roughly 15 minutes on AWS and Kubernetes.

My [portfolio](https://ravipalavai.vercel.app) itself is a React and TypeScript single-page app I designed and built, with hand-rolled CSS and a custom interactive demo for each project. [Browse all case studies and demos](https://ravipalavai.vercel.app/projects).
